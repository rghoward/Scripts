# Course Style Guide

## Learning design

- Begin each lesson with a business reason and clear objectives.
- Introduce only one or two new ideas at a time.
- Use Blue Ridge Outfitters when it adds meaningful continuity.
- Give students both guided practice and an independent challenge.
- End with a recap and a preview of the next lesson.

## Code conventions

- Target Python 3.11+.
- Use descriptive `snake_case` names and f-strings.
- Prefer `pathlib.Path` for file locations when files are introduced.
- Use context managers and UTF-8 encoding for text files.
- Keep examples concise enough to discuss on one screen.
- Do not introduce advanced syntax before it is taught.

## Paired-file conventions

Instructor files use `INSTRUCTOR NOTE:`, `COMMON MISTAKE:`, and `IF TIME:` comments when useful. They contain working solutions and expected output when it supports instruction. Starter files use brief explanations and visible `TODO:` markers; they never hide a solution in comments or unused code.

## Business-data conventions

Blue Ridge Outfitters is a fictional outdoor retailer. Values and records are invented for instruction, reproducibly generated, and not representations of a real company.
