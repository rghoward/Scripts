# Python for Analytics Bootcamp

Welcome to the Blue Ridge Outfitters learning environment. This 15.5-hour bootcamp helps incoming analytics master's students move from clear, small Python scripts to practical data analysis in Jupyter notebooks.

## Getting started

1. Create and activate a Python 3.11+ virtual environment.
2. Install the course packages with `python -m pip install -r requirements.txt`.
3. Open this folder in VS Code.
4. Start with the Day 1 **starter** files. Instructor files are complete teaching references.

All business data is fictional, deterministic, and created for this course. The API lesson uses the public Open-Meteo Forecast API and includes a local fallback response for offline teaching.

## Course folders

- `day01_python_fundamentals/` — Python scripts: variables through functions.
- `day02_working_with_data/` — scripts for collections, files, JSON, and an API.
- `day03_numpy/` — Jupyter notebooks for numerical arrays.
- `day04_pandas_foundations/` — Jupyter notebooks for DataFrames.
- `day05_analysis/` — Jupyter notebooks for an end-to-end analysis.
- `data/` — the fictional Blue Ridge Outfitters data package.
