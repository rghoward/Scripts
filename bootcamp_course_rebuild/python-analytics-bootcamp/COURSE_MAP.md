# Course Map

## Audience and outcome

This course serves incoming Analytics Master's students. Students begin with runnable `.py` scripts and transition to notebooks only after gaining confidence with core Python. By the end, they can acquire, clean, analyze, visualize, and export a small business analysis.

## Schedule

| Day | Contact time | Format | Focus |
| --- | ---: | --- | --- |
| Monday | 3.5 hours | Python scripts | Variables, decisions, iteration, functions |
| Tuesday | 3.5 hours | Python scripts | Collections, files, JSON, API data |
| Wednesday | 3 hours | Notebooks | NumPy arrays, vectorization, masking |
| Thursday | 2.5 hours | Notebooks | pandas DataFrame foundations |
| Friday | 3 hours | Notebooks | EDA, merges, weather data, plots |

The lesson time budgets leave room for setup, questions, breaks, and recap; they are not continuous lecture time.

## Lesson inventory

### Day 1 — Python fundamentals (3.5 hours)

| Lesson | Minutes | Core outcome |
| --- | ---: | --- |
| 01 Getting started and variables | 35 | Build a retail order total with basic values and f-strings. |
| 02 Conditionals | 40 | Apply pricing and shipping decisions with Boolean logic. |
| 03 Iteration | 50 | Aggregate a short set of daily business values. |
| 04 Functions | 50 | Write reusable calculations with parameters and returns. |
| 05 Day 1 practice | 35 | Assemble a small order-pricing script. |

### Days 2–5

The remaining folders are intentionally reserved for the approved next build phase: working with data, NumPy, pandas foundations, and the final analysis workflow.

## Paired artifacts

Each lesson has a matching `_instructor` and `_starter` file. Instructor files are complete, annotated teaching references. Starter files preserve the same section order but provide scaffolding and TODO prompts without solutions.
