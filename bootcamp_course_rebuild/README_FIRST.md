# Codex Handoff

Place this folder in the parent workspace where Codex will work.

Recommended layout:

```text
course-rebuild/
├── codex_bootcamp_handoff/
│   ├── CODEX_BUILD_SPEC.md
│   ├── COMPANY_AND_DATA_GUIDE.md
│   ├── CODEX_START_PROMPT.md
│   └── README_FIRST.md
├── Archive.zip                     # optional historical reference
├── day05e_sklearn.ipynb            # optional historical reference
└── python-analytics-bootcamp/      # Codex creates this
```

Open `course-rebuild` in VS Code. Give Codex the contents of `CODEX_START_PROMPT.md` or tell it to read that file and execute it.

The build specification is the controlling document. The company guide controls example style and dataset continuity.
